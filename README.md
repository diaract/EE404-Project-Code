# EE404-Project-Code
EE404 Antennas Project — MATLAB code for calculating and plotting the array factor and total radiation pattern of a 5-element linear dipole antenna array operating at 1.3 GHz. The code evaluates phase shifts of 0°, 15°, 30°, and 45°, extracts main-beam direction, HPBW, and SLL, and provides CST-compatible θ = 90° radiation cuts for comparison.
